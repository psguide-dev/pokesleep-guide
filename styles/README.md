## 編集方針

- 同じセレクターと適用条件の指定を検索し、対象のルールを直接修正します。末尾への追加だけで調整しないでください。
- メディアクエリー、詳細度、`!important`、読み込み順は表示の優先順位を変えます。別の条件を統合するときは、縦横両方向と境界の画面幅を確認してください。
- 余白などの短縮指定と個別指定には順序依存があります。例えば `margin` と `margin-top` を無条件に並べ替えないでください。
- バージョン番号付きのクラスは既存HTMLから参照しています。CSS整理だけで名前を変更しないでください。
