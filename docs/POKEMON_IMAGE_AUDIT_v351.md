## 整理方法

1. まず公開用フォルダから、表示に使わない旧画像を除外する。受領ZIP・元データは残す。
2. 復元対象を元ファイルから削除する場合は、復元処理・ハッシュ検証・初期画像参照・テストも同時に変更する。単独削除では次のビルドで戻るかビルドが失敗する。
3. 画像マップだけの参照は、姿違い・フォールバック用途を整理してから削除判定する。
4. 重複していても使用中の参照先は残す。参照を一本化する場合は画像IDとの対応を維持する。
