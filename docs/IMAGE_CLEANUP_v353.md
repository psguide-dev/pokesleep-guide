# v353 旧ポケモン画像の控え整理

- 旧画像のみのZIPを266個削除。
- 混在ZIPを7個整理し、現行画像の内容とSHA-256を保持。
- 合計221,847,472バイト（約211.6 MiB）削減。
- 旧寝顔の復元モジュールと旧チェックポイント処理を削除。
- 履歴照合用の画像名・ID・ハッシュなどのメタデータは保持。
- 現行1,432画像の全割り当てはv352から変更なし。
- タマゲタケ・モロバレルの確認待ち寝顔8枚を保持。
- ビブロ側の元データとGit履歴は削除しない。

検証: 全アーカイブのSHA-256、現行メンバー集合、旧画像の不在、2回のビルド、画像参照、図鑑とボックスの画像先行追加、標準顔画・全身画を確認。

受領ZIPは公開サイトに含まれないため、この整理による公開サイトの画像変更はありません。
