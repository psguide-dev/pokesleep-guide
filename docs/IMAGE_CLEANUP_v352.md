# 旧画像の削除（v352）

2026年10月4日：棚卸しに基づき、未使用の旧画像1,165枚（96.80 MiB）を画像フォルダから削除しました。

- 現在使う1,432ファイルのパスとポケモン・寝顔との対応はv351と同一です。
- タマゲタケ・モロバレルの顔・全身・確認待ち寝顔8枚は残しています。寝顔名・IDと能力は確認待ちのままです。
- ユキカブリ・ユキノオーの最新★2画像も保持しています。
- 旧寝顔、旧顔・全身、除外済み誤画像、旧顔シートを削除し、古い画像マップの参照を整理しました。
- ビルド時の旧寝顔復元を停止。残る受領ZIPの復元処理も削除対象をスキップします。
- 受領ZIPと対応表は控えとして保存しています。Gitの過去履歴は変更していません。
- 削除対象のパス・ハッシュはdata-import/retired-pokemon-images-v352.jsonに記録。異なる内容の画像が同じパスに追加された場合は、無条件で削除せず検証で停止します。

検証：通常ビルド、再ビルド時に旧画像が戻らないこと、現在の全画像参照が有効なこと、元の画像と寝顔IDとの対応が変わらないこと、画像先行データの表示、寝顔画像差し替え、全身・顔画像の接続を確認しました。
